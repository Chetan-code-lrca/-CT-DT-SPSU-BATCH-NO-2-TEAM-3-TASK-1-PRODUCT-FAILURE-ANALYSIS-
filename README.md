# Product Failure Analysis — Team 3

Workspace for the SPSU CSE product-failure-analysis task. This repository currently provides a report structure only; it does not contain a dataset, completed findings, or verified root causes. Replace the template sections with evidence from the assigned case before submitting.

## Suggested workflow

1. Record the exact product, failure definition, and scope.
2. Preserve the source of every observation and the date it was collected.
3. Separate observed facts from hypotheses and confirmed causes.
4. Quantify impact only when the underlying data supports it.
5. Recommend corrective actions with an owner, priority, and verification measure.

## Files

- [Analysis template](docs/analysis-template.md) — report outline and evidence table.
- [Data handling notes](data/README.md) — rules for storing source data.

## Reproducibility

Do not invent data, percentages, dates, or causal explanations. Do not commit confidential customer data or credentials. Note limitations and unresolved questions explicitly.
